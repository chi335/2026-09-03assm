## 1. 컴퓨터란? (Computer)

컴퓨터는 데이터(정보)를 입력받아, 정해진 명령(프로그램)에 따라 처리하여 결과를 출력하고 저장하는 전자 장치입니다.

> **"사람이 시킨 일을 엄청나게 빠르고 정확하게 처리해 주는 전자 계산기"**

컴퓨터는 크게 두 가지 핵심 요소로 구성됩니다.
* **하드웨어 (Hardware):** 눈에 보이는 물리적 장치 (본체, 모니터, 키보드 등)
* **소프트웨어 (Software):** 하드웨어를 움직이는 운영체제 및 응용 프로그램 (OS, 앱 등)

---

## 2. CPU (Central Processing Unit, 중앙처리장치)

CPU는 컴퓨터의 **'두뇌'**에 해당하며, 컴퓨터에서 일어나는 모든 연산과 제어를 담당합니다.

* **주요 역할:** 프로그램의 명령어를 읽어와서 해석하고, 수학적 계산이나 논리적 판단을 수행합니다.
* **핵심 구성 요소:**
  * **ALU (Arithmetic Logic Unit, 연산장치):** 덧셈, 뺄셈, 논리 연산 등을 실제로 수행합니다.
  * **CU (Control Unit, 제어장치):** 명령어를 해석하고 컴퓨터의 각 장치들에게 작업 지시를 내립니다.
  * **Register (레지스터):** CPU 내부의 아주 빠른 임시 저장 공간입니다.

---

## 3. Memory (메모리, 기억장치)

메모리는 컴퓨터가 데이터나 프로그램을 저장하는 공간입니다. 사람이 작업할 때 쓰는 **'책상'**에 비유할 수 있습니다.

| 기억장치 종류 | 특징 및 비유 |
| :--- | :--- |
| **주기억장치 (RAM)** | • 현재 실행 중인 프로그램과 데이터를 임시로 올려두는 공간<br>• 전원이 꺼지면 내용이 사라지는 휘발성 메모리이지만 속도가 매우 빠름<br>• *(비유: 책상이 넓을수록 여러 작업을 한 번에 하기 쉬운 것과 같습니다)* |
| **보조기억장치 (SSD / HDD)** | • 사진, 동영상, 파일 등을 영구적으로 저장하는 공간<br>• 전원이 꺼져도 데이터가 유지됨<br>• *(비유: 책장이나 서랍에 비유됩니다)* |
| **캐시 메모리 (Cache)** | • CPU와 RAM 사이의 속도 차이를 줄이기 위해 CPU 내부에 위치한 초고속 메모리 |

---

## 4. Debug? (디버깅)

질문해주신 'Debg'는 **Debugging(디버깅)**을 의미합니다.

* **뜻:** 소프트웨어나 하드웨어에서 발생한 오류(**버그, Bug**)를 찾아서 수정하는 과정입니다.
* **유래:** 과거 거대한 컴퓨터 내부의 전자 회로에 진짜 **벌레(Bug, 나방)**가 들어가 합선으로 고장이 났던 역사적 사건에서 유래했습니다.
* **왜 중요한가?:** 코드를 작성하는 것만큼이나, 작성한 코드의 문제점을 찾아서 올바르게 작동하도록 고치는 디버깅 작업은 개발자에게 핵심적인 능력입니다.

## 5. AI 시대에서 왜 Assembly(어셈블리)를 배워야 할까?

AI 시대에는 Python 같은 고성능 라이브러리(PyTorch, TensorFlow)나 ChatGPT 같은 AI 툴이 코드를 대신 짜주는 경우가 많습니다. 그렇다면 왜 가장 밑바닥 언어인 **어셈블리(Assembly)**를 배워야 할까요?

### ① 극강의 Performance (성능) 최적화
* AI 모델(LLM, 이미지 생성 모델 등)은 천문학적인 연산량을 필요로 합니다.
* Python이나 C++로 짜여진 AI 프레임워크도 결국 최하단에서는 어셈블리 및 기계어로 변환되어 하드웨어에서 실행됩니다.
* 온디바이스 AI(스마트폰, 로봇, 자율주행차 등)처럼 제한된 환경에서 AI를 돌리려면, 메모리와 CPU/NPU/GPU의 레지스터 수준까지 최적화해야 하는 경우가 많습니다.

### ② 하드웨어(NPU/GPU/TPU)의 깊은 이해
* 요즘은 CPU 외에도 AI 전용 반도체(NPU, GPU)가 핵심입니다.
* 새로운 AI 칩셋이 나올 때, 해당 칩의 성능을 100% 끌어올리는 AI 컴파일러나 로우레벨 커널을 작성하는 엔지니어는 어셈블리 수준의 이해가 필수적입니다.

### ③ 보안 (Security) 및 리버스 엔지니어링
* AI 모델이나 AI 기반 프로그램의 보안 취약점을 분석하거나, 악성코드를 분석할 때 소스 코드가 없는 상태에서 실행 파일(바이너리)을 분석해야 합니다. 
* 이때 어셈블리어를 읽을 수 있는 능력이 필수입니다.

### ④ AI가 만드는 '블랙박스'의 내부 동작 파악 (디버깅의 끝판왕)
* AI가 아무리 코드를 잘 짜주더라도, 시스템의 가장 밑단에서 발생하는 심각한 메모리 오류나 병목 현상은 AI가 해결해 주지 못합니다. 
* 컴퓨터의 작동 원리(CPU, 메모리, 레지스터)를 가장 명확히 보여주는 언어가 어셈블리이므로, 문제 해결 능력을 비약적으로 높여줍니다.

## 1. 어셈블리어의 개요 및 특징 (Welcome to Assembly Language)

* **어셈블리어란?:** 기계어(0과 1)와 1:1로 대응되는 사람이 읽을 수 있는 최하위 수준(Low-Level)의 기계 밀착형 프로그래밍 언어입니다.
* **고급 언어 vs 저급 언어:**
  * **고급 언어 (C, Java, Python):** 하드웨어 구조를 몰라도 작성 가능, 가독성과 이식성이 뛰어남.
  * **저급 언어 (Assembly):** CPU의 레지스터, 메모리 구조, 명령어 집합(ISA)에 정밀하게 종속됨.
* **어셈블리어를 배우는 목적:**
  * 하드웨어(CPU, Memory)의 내부 동작 원리와 시스템의 세부적인 작동 방식을 깊이 이해할 수 있음.
  * 임베디드 시스템, 바이오스(BIOS), 백신/보안(리버스 엔지니어링), 성능 극대화(최적화) 영역에서 필수적임.

---

## 2. 가상 머신 개념 (Virtual Machine Concept)

컴퓨터 시스템은 여러 단계를 거쳐 상위 레벨 명령을 최하위 하드웨어 명령으로 해석합니다.

1. **High-Level Language (고급 언어):** C, C++, Java 등
2. **Assembly Language (어셈블리어):** 기계어 기호화 (Mnemonic 사용)
3. **Instruction Set Architecture / Machine Language (기계어):** CPU가 해석 가능한 0과 1의 바이너리 코드
4. **Microarchitecture (마이크로아키텍처):** CPU 내부의 데이터 경로(Data Path) 및 ALU, 레지스터 회로
5. **Digital Logic (디지털 논리 회로):** 논리 게이트(AND, OR, NOT) 및 실질적인 전자 회로

---

## 3. 데이터 표현 방식 (Data Representation)

### ① 진법 변환 (Numbering Systems)
* **2진수 (Binary):** 컴퓨터 내부 기본 표현 방식 (0과 1).
* **16진수 (Hexadecimal):** 2진수를 사람이 쉽게 읽을 수 있도록 4비트씩 묶어 표현 (0~9, A~F).
* **10진수 (Decimal):** 사람이 사용하는 일반적인 수 표현 방식.

### ② 데이터 크기 단위 (Data Units)
| 단위 | 크기 및 범위 |
| :--- | :--- |
| **1 Byte** | 8 bits (0 ~ 255 또는 -128 ~ +127) |
| **1 Word** | 2 Bytes = 16 bits |
| **1 Doubleword (Dword)** | 4 Bytes = 32 bits |
| **1 Quadword (Qword)** | 8 Bytes = 64 bits |

---

## 4. 정수의 표현 및 음수 처리 (Signed & Unsigned Integers)

* **부호 없는 정수 (Unsigned Integer):** 모든 비트를 양수 값(크기)을 나타내는 데 사용합니다.
* **부호 있는 정수 (Signed Integer):** 가장 왼쪽 비트(MSB, Most Significant Bit)를 부호 비트로 사용 (0 = 양수, 1 = 음수).
* **2의 보수법 (2's Complement):** 컴퓨터에서 음수를 표현하고 덧셈 회로만으로 뺄셈을 처리하기 위한 방식입니다.
  * **구하는 방법:** 비트를 반전(1의 보수)시킨 후 +1을 해줍니다.
  * **예시 (+5 → -5):**
    * `+5` = `0000 0101₂`
    * 비트 반전 = `1111 1010₂`
    * `+1` 실행 → `-5` = `1111 1011₂`

---

## 5. 문자 표현 (Character Storage)

* **ASCII 코드:** 7비트(또는 8비트 Extended ASCII)를 사용하여 알파벳, 숫자, 특수기호 등을 표현 (예: `'A' = 65 = 0100 0001₂`).
* **Unicode:** 전 세계의 모든 언어와 기호를 표현하기 위해 만든 16비트/32비트 문자 인코딩 표준 (UTF-8, UTF-16 등).

---

## 6. 기본 불리언 연산 (Boolean Operations)

어셈블리어 및 디지털 회로에서 핵심이 되는 4가지 논리 연산입니다.

* **AND (논리곱):** 둘 다 1일 때만 결과가 1 (특정 비트를 0으로 지우는 마스킹 작업에 사용).
* **OR (논리합):** 둘 중 하나라도 1이면 결과가 1 (특정 비트를 1로 설정할 때 사용).
* **NOT (논리부정):** 1은 0으로, 0은 1로 반전 (1의 보수).
* **XOR (배타적 논리합):** 두 비트가 서로 다를 때만 1 (비트 비교, 또는 특정 비트 반전/초기화에 사용).
